# Original Hero instead of Spider-Man

The first version used a downloaded Marvel Spider-Man spritesheet. We replaced it with an original spider-themed Hero because a public portfolio judged by recruiters shouldn't carry copyright/trademark risk or read as a fan project, and because the old sheet had no swing frames for web-swinging anyway. The comic style and web-swinging stay; the Marvel character goes. Don't reintroduce Spider-Man art, names or likeness.
